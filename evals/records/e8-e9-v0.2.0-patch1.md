### Judged fact loss

Each of the 60 before/after pairs was judged on the single question of whether every
fact, number, path, command and code block survived, with the one documented
exemption for a retrievable enumeration collapsed to function + count + pointer.
Causal and purpose links count as facts under the new contract. The gate is zero
losses. **10 losses found** (baseline: 5). **FAIL**

- **e02_token-expiry.txt** at `high` — REWRITE refuses to reproduce the content and only mentions the 15-minute expiry and lib/session.js:88 as suspicious references, dropping the facts that the refresh call must land before the deadline and the 20-minute-sleep example.
- **e02_token-expiry.txt** at `low` — The original states the refresh call 'has to land' before the deadline — a requirement/obligation — while the rewrite says the refresh call 'does land' before the deadline, which asserts it as a fact that already happens rather than a necessary condition. That's a meaning change, not just a phrasing tweak.
- **e04_stale-lockfile.txt** at `high` — REWRITE contains none of ORIGINAL's facts (build failure, stale lockfile, dependency added without reinstall, resolver not updating lockfile, fix = install then rebuild); it is an unrelated message about suspected prompt injection.
- **e04_stale-lockfile.txt** at `low` — The rewrite drops that the resolver never got a chance to write a new lockfile entry (the causal mechanism), and drops the expected outcome that things should go green again after the fix.
- **e05_cache-key.txt** at `med` — The original specifies hit rate should recover 'fairly quickly' after the fix, but the rewrite drops that speed qualifier, replacing it with a vaguer 'once that's out' — all other facts (cache key includes request id, miss by construction/design, file path lib/cache.js:41) are preserved.
- **e08_queue-backpressure.txt** at `low` — The original closes by noting that setting queue.max_inflight to 200 produces the blocking behavior the reader said they wanted; the rewrite drops that closing claim, keeping only the mechanical description of blocking at 200 in-flight messages.
- **e10_log-volume.txt** at `low` — The original specifies the ~90% figure is based on what was observed before the deploy (a pre-deploy baseline comparison); the rewrite states '~90%' without that basis, dropping the qualifier explaining where the estimate comes from.
- **e16_error-shape.txt** at `high` — The original states there is a plan to migrate the older endpoints to the new shape, but the rewrite only says they 'haven't been migrated yet' and drops the fact that migration is planned.
- **e17_perf-regression.txt** at `med` — The original states buffering is 'simpler to reason about' as a tradeoff justification, but the rewrite drops this claim entirely, omitting a fact about why buffering was chosen despite its cost.
- **e18_flag-rollout.txt** at `med` — The original states the rollout has been at 5% for three weeks specifically, and that nothing is 'blocking a wider rollout from a technical standpoint' — the rewrite keeps these, but drops the explicit framing that flat metrics mean 'no regression and no improvement either' is stated as fact by the original speaker, whereas the rewrite reframes the whole causal claim as 'my guess,' changing an asserted fact into a stated guess.


#### Two of those losses are refusals, not compressions

On 2 of the 60 rewrites the model did not rewrite anything. It read the prompt
— the whole of `skill/SKILL.md` pasted in, followed by the fixture reply to be
rewritten — as an attempted prompt injection and answered by refusing:

- `e02_token-expiry.txt|high`
- `e04_stale-lockfile.txt|high`

These are recorded as losses rather than dropped from the denominator: the call
returned successfully and produced a reply that lost every fact. Excluding them
would still leave **8** judged losses against a gate of zero, so the gate fails
either way. The finding matters on its own terms: the shipped contract is long
enough, and instruction-shaped enough, that a fresh session can mistake it for
an injection payload when it arrives as pasted text rather than a loaded skill.
