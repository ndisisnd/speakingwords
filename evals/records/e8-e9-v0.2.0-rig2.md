## Eval-design findings (recorded for the next plan)

1. **E9's prompt set presupposes shared context.** Questions say "our tokens",
   "our cache". A grounded installed agent honestly asks "which repo?" instead
   of role-playing — the first rig attempt scored 55% for exactly this. The
   pasted baselines only "worked" because a contract-in-prompt model plays
   along. The prompt set needs self-contained questions.
2. **The terse voice and the DM-register axis fight.** Terse mandates point
   form; judges read bulleted answers as "support-doc, not Slack". The rubric
   and the voice contract need to agree about what terse Slack looks like.
3. **The hook cannot bounce register.** The >=95% post-bounce gate assumes
   bounces catch what judges catch; they cannot. Either the gate's meaning
   changes (judged rewrite, not hook bounce) or the target moves.
